## What I Practiced

During this assignment I practiced:

- Typed variables
- Typed functions
- Optional parameters
- Typed arrays
- `map()`
- `filter()`
- Chaining array methods
- Interfaces
- Nested interfaces
- Optional properties

1. Student profile with typed variables

6. Book interface

Run the comipled JavaScript:
node homework.js
